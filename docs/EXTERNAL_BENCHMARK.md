# External benchmark: what synthetic training costs

Two independent prototype implementations of the same idea were produced during
development — a complete Python package (~3,100 LOC) and a web-application port
of it. Both were trained on synthetic data generated by a formula, and both say
so plainly. This document measures what that costs, because the answer is not
obvious and the number is useful when writing a methods section.

Reproduce with:

```bash
python scripts/05_external_benchmark.py --adapter quadcond_external \
    --model-path <their>/demo_output/demo_model.joblib \
    --src <their>/src
python scripts/05_external_benchmark.py --adapter quadcond_self
```

## The evaluation

Held out from both models: **1,005 G-quadruplex sequences with experimentally
determined folding topology** (CD, NMR, X-ray; PDB entries and literature
curation) from the G4ShapePredictor dataset — the `experimental` /
`biophysical` tier of this atlas. For the folding task, those same 1,005
sequences are scored against 1,005 dinucleotide-shuffled counterparts with
identical mono- and dinucleotide composition.

Neither model saw these labels during training: the synthetic model never saw
real data at all, and this package's numbers are grouped out-of-fold, with
sequence clusters kept whole across the split.

## Results

| | synthetic-trained model | this package | baseline |
|---|---|---|---|
| topology, balanced accuracy | **0.319** | **0.724** | 0.333 (chance) |
| topology, accuracy | 0.449 | 0.752 | 0.485 (always parallel) |
| antiparallel recall | **0 / 216** | 0.694 | — |
| folding, AUROC | **0.625** | **0.865** | 0.5 |
| folding, Brier | 0.278 | 0.151 | 0.25 |
| folding, ECE | 0.201 | 0.021 | — |
| mean p on real G4s vs shuffles | 0.722 vs 0.679 | — | — |

Confusion matrix for the synthetic-trained topology head on real measurements:

| | pred parallel | pred antiparallel | pred hybrid |
|---|---:|---:|---:|
| **true parallel** (487) | 426 | 16 | 45 |
| **true antiparallel** (216) | 130 | 0 | 86 |
| **true hybrid** (302) | 271 | 6 | 25 |

## The finding that matters

The synthetic model's own held-out evaluation, run correctly with a grouped
split on its own data, reports **AUROC 0.869** for folding and **accuracy
0.737** for topology. On real measurements the same model scores **0.625** and
**0.449**.

Those synthetic numbers are almost exactly what a genuinely working model
reports. That is what makes them dangerous: nothing in the metric table signals
that the model has learned nothing transferable. The only thing that separates
the two cases is where the labels came from — which is why evidence tier,
label class and dataset fingerprint are stored per row in this atlas rather than
described in a README.

A second detail is worth noting: the synthetic model is *below* the
always-predict-parallel baseline on accuracy and *below chance* on balanced
accuracy, and it never once predicts antiparallel correctly across 216 real
antiparallel structures. It is not weakly right; on the class distinction that
carries the biology, it is not right at all.

None of this is a defect in that package's engineering, which is careful — group
splits by sequence hash, sigmoid calibration, ECE reporting, dataset
fingerprinting, artifact checksums, a model card that states its own limits.
Several of its ideas were adopted here (see `docs/COMPARISON.md`). The gap is
entirely in the data.

## Why the synthetic sequences cannot support the labels

Running this package's motif finders over the 240 unique synthetic sequences:

| | labelled G4 | labelled i-motif |
|---|---:|---:|
| contains a canonical G4 motif (G₃N₁₋₇ ×4) | **7.5%** | 0% |
| contains a relaxed G4 motif (G₂N₁₋₇ ×4) | 33.3% | 0.8% |
| contains a canonical i-motif motif (C₃N₁₋₁₂ ×4) | 0% | **26.7%** |
| mean G4Hunter score | +0.57 | −0.57 |

Fewer than one in twelve sequences labelled "G4" can form one under the standard
motif definition. The generator produces G-rich and C-rich random sequence, and
the labels are then computed from a hand-written linear equation over the
model's own feature vector — so the coefficients in that equation (0.52·log[K⁺]
for G4 folding, −1.15·(pH − 6.1) for i-motif folding) *are* the biology the
model can recover, and nothing else is learnable. Recovering them is a valid
test of the software. It is not evidence about DNA.
